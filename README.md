# full-dimensional-srns-explorer
Code and programmatic methods surrounding a research project at ULB surrounding routed Bell experiments, and the characterization of short-range no-signaling behaviors. This specific repo implements methods working on the full-dimensional space of behaviors.

SEE ALSO THE ASSOCIATED WORK :
- [correlators-dimensional-srns-explorer](https://github.com/LgBossu/correlators-dimensional-srns-explorer)
    - This newer repository aims to uncover similar structures and results, but does so by working in the more constrained space of correlators-derived behaviors, where coordinates are that of the correlators $<A_x>$, $<B_y>$, $<A_xB_y>$.
    - In contrast, we work here by representing behaviors in the full-dimensional space, where coordinates correspond to probabilities of the form $p(ab|xy)$.
